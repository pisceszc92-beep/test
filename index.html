# 人工智能在经济管理研究中的应用

**授课人：** 张晨（西北农林科技大学经济管理学院）

**课程性质：** 研究生方法类课程 · 8 讲 · 2026 年夏季学期

---

这是一套面向经济管理类研究生的 **AI 工具实操教材**，共 8 讲。课程目标不是把读者教成程序员，而是让读者把大语言模型与 Agent 真正接进自己的科研工作流——读文献、理数据、跑回归、写论文，每一步都有 AI 可接手、可放大的地方。

## 你会学到什么

| 讲次 | 主题 | 一句话概括 |
|---|---|---|
| 第一讲 | AI 认知与工具概览 | 搞清楚 LLM 能做什么、不能做什么，选对工具 |
| 第二讲 | 环境安装与引擎配置 | 装好一条能跑通的 AI 工具链 |
| 第三讲 | Agent 基础操作 | Skills 入门、项目规则与 Git 版本控制 |
| 第四讲 | Agent 进阶 | 自定义 Skill 与多 Agent 编排 |
| 第五讲 | 知识库构建与学术品味蒸馏 | 把文献变成 AI 能调用的知识，把学者风格变成可复用的 Agent |
| 第六讲 | AI 辅助数据采集 | 爬虫原理、API 发现与生产级爬虫 |
| 第七讲 | AI 辅助文本分析 | LLM 文本分类、情感分析与信息提取 |
| 第八讲 | AI 辅助规范实证研究 | 研究设计、Stata 规范与三个完整案例 |

## 如何使用本教材

- 每讲都包含 **上节** 与 **下节** 两部分，对应一次课的两个 45 分钟。
- 建议在电脑前同步操作：**每装完一个工具、每跑完一步，立刻验证**，不要攒到最后统一验证。
- 左侧边栏可搜索、可折叠，点击目录即可跳转到任意讲次。
